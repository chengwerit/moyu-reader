## 环境教训（重要，跨项目有效）

1. **`grep -c $'\r$'` 在本机 Bash 工具里不可信** —— 模式退化成匹配所有行，
   每个文件都测出"全 CRLF"。本次因此漏掉 updater.js 其实是 LF。
   **行尾/编码检查一律用 Python 字节计数**：
   `d.count(b'\r\n')` vs `d.count(b'\n')`。
2. **本机启动的 Edge 默认 DoH 解析器不可达** —— 页面所有外网 fetch 挂起
   （baidu / github 全 timeout），而 bash curl 直连正常（~0.4s）。
   **启动调试浏览器必须加 `--disable-features=DnsOverHttps`**，
   否则浏览器 E2E 全是假超时，极难排查。
3. **api.github.com 本机直连即通**；13075 / 7890 代理端口实际没监听，
   推送脚本里的"直连兜底"才是真正生效的路径。
4. **verify.cjs 是 IDB 模式脚本** —— 它直读 IndexedDB（第 3/4 节），
   在 server.ps1 文件存储模式下会永久挂起（objectStore 不存在，Promise 不 settle）。
   要跑它就另起 `python -m http.server 8898` + `APP_PORT=8898`。
5. **`process.exit()` 会丢输出** —— stdout 重定向到文件时异步写未 flush 就退出，
   表现为输出少一半。两个验证脚本已改用 `process.exitCode`。
6. **调试浏览器保活**：PowerShell 后台任务 + 结尾 `Start-Sleep`，
   启动器进程退出会被任务回收机制杀掉整个浏览器。
